# Gizai UI v2 (Paperclip-level look and feel) Implementation Plan

> Executed inline (superpowers:executing-plans), TDD for every piece of logic; UI verified with the headless
> cage probes (`scripts/ui-test.sh`) and screenshots.

**Goal:** Bring the UI to Paperclip's level: one design system, wide right-side drawers for every form, a
Markdown editor with a toolbar, a Paperclip-style task list, task page and agent page.

**Spec:** Jeffrey's request of 2026-10-06 (drawers from the right, at least 1024px; a proper Markdown editor
with a formatting toolbar; a design system for colours, icons and typography; Paperclip as the reference,
screenshots of its issues list, CEO agent page and issue page). The design system is the visual spec:
https://claude.ai/artifact/8fVNzRghAU24wMaq5ZcdtD (tokens, brand book, 18 components, icons). Its tokens and
component CSS are kept in this repo under `design/` and `src/styles/components.css`.

## Global constraints

- Every colour, size and radius comes from the design system's tokens (`src/styles/tokens.css`, generated
  from `design/tokens.json` by `scripts/tokens-css.mjs`); no literal colours in components.
- Dark theme by default; `t` toggles light. Teal (`--live`) only means "an agent is working now".
- Every create and edit form is a Drawer from the right, `min(1024px, 100vw - 48px)` wide.
- Every Markdown field uses MarkdownEditor with the toolbar (heading, bold, italic, quote | code, link |
  numbered, bullet, checklist | rule, table).
- Icons: lucide-react, 16px, stroke 1.75; status glyphs from `StatusIcon` (shared paths with the design system).
- Existing behaviour and tests stay green; the headless UI probes are updated to the new markup.

## Tasks

1. **Tokens, base styles, icons.** `design/tokens.json` + generator → `src/styles/tokens.css`;
   `src/styles/components.css` (= the design system's `bundle.css`); `app.css` keeps only layout; lucide-react
   replaces `Icon.tsx`; `StatusIcon` draws the design system's glyphs; dark by default.
2. **Shell.** Rail with the org tile; Sidebar per the design system (New task, Search, Inbox; Work; Projects
   with "+"; Agents with role icons and a "1 live" tag; Company).
3. **Drawer.** `Drawer` component (head, scrolling body, sticky foot, Escape/scrim close, unsaved-changes
   guard); New task, client, project, person, agent, doc and doc-version forms move into drawers with form
   sections. New task gains description, priority and assignee.
4. **Markdown toolbar.** Pure, tested formatting commands (`src/lib/mdFormat.ts`) and a toolbar in
   `MarkdownEditor`; Ctrl+B / Ctrl+I / Ctrl+K; every Markdown field uses it (project goal included).
5. **Task list and board.** View toolbar (New task, list/board, Filters, Sort, Group), grouped rows per the
   design system, tested grouping/sorting/filtering (`src/lib/taskView.ts`); board restyled.
6. **Task page.** Paperclip layout: header line, title, description, attachments, run card, tabs with icons,
   closable properties panel.
7. **Agent page.** `#/agent/<id>`: header with Assign task / Run / Pause and state, latest run, 14-day run
   charts (core `runs::daily_stats`, tested), recent tasks, settings in a drawer. Sidebar and Team link here.
8. **Other pages.** Clients, client, projects, project, users, team, settings, inbox, docs restyled with the
   design system's components.
9. **Verify.** `npm test`, `cargo test --workspace`, `scripts/ui-test.sh` (probes updated), screenshots of
   every page, commit per task.
