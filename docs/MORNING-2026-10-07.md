## Try it

```sh
cd ~/Herd/gizai
git checkout v0.3-chat
scripts/run.sh
```

1. **Chat:** press *Set up the Team Lead*, then *Add agent*. Go back to Chat and try "What needs my attention?" or "Add a client Kade Logistics in Rotterdam".
2. **Agent test:**
   - On Team, click an empty place (for example Backend).
   - Link a project to a git repository.
   - Make a task with the `backend` label and press Run.

   The agent now runs without your hooks and skills.
3. **Installer (optional):** `./install.sh` puts Gizai in your app launcher. `./install.sh --uninstall` removes it; your data stays.

## Final review

Verdict: ready with fixes. No critical issues. Fixed tonight, each with a test that failed first:

- **The chat could forget a conversation** after a stopped first answer or a failed resume. It now keeps the session.
- **The chat could give an agent `bypassPermissions` or unlimited Bash and start it.** It can't any more; only you can, in the agent form. It also can't link a folder that isn't a git repository.
- **"Attach a file" now takes only files you named in that chat or files inside a linked repository.**
- **`scripts/ui-test.sh` now builds the chat helper itself.**

Nine smaller findings are listed as deferred in `docs/v0.3-notes.md`.
