> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Tauri 2 desktop app on Jeffrey's Linux PC where he first manages users, clients, projects and tasks (list + kanban + detail with a Markdown editor), then sets up his own teams of Claude Code agents (roles, instructions, heartbeats) that work tasks in git worktrees, with a live run log, Stop, and the Testing/Review gates.

**Revision (Jeffrey, 2026-10-06):** start empty: no agents are seeded; Jeffrey sets up agents himself, with heartbeats. Build the CRUD screens (Users, Clients, Projects, Tasks) first so he can use and test the UI early, then the agent integration. Repo at `~/Herd/gizai` (local git, no remote).

**Architecture:** Rust workspace: `gizai-core` (SQLite store, domain, workflow gates; never imports Tauri), `gizai-agents` (Claude Code driver, stream parser, git worktrees, process control; never imports Tauri), and `src-tauri` (thin adapter: commands, events, run manager). React 19 + TypeScript UI in `src/`, calling the core only through `src/api.ts`. One SQLite file in the data dir; UI loads from Tauri's custom protocol (no server in production).

**Tech Stack:** Rust 1.98 (edition 2024), Tauri 2.12.x, rusqlite 0.40 (`bundled`), rusqlite_migration 2.x, uuid (v7), serde/serde_json, tokio (process, io-util, time, sync, rt-multi-thread, macros), libc; React 19, TypeScript, Vite, @tanstack/react-table 8 + @tanstack/react-virtual 3, @dnd-kit/core + @dnd-kit/sortable, CodeMirror 6 (`codemirror`, `@codemirror/lang-markdown`), react-markdown + remark-gfm, fractional-indexing, vitest.

## Global Constraints

- Product name and identifiers: `gizai` everywhere (crate names `gizai-core`, `gizai-agents`, app identifier `ai.gizai.app`, DB file `gizai.db`, branches `gizai/<key>-<slug>`). Licence: MIT.
- Tauri 2 stable (2.12.x), WebKitGTK on Linux. No embedded browser feature. No local web server in production builds (Vite dev server only under `tauri dev`).
- Agents: Claude Code only in v0.1 (`adapter = 'claude_code'`), spawned as `claude -p … --output-format stream-json --verbose --session-id <uuid> --permission-mode <mode>` in the task's git worktree. Agents never merge, never push, never move cards themselves; Gizai moves cards from the agent's reported outcome.
- First start seeds only: the organisation, the user (from `$USER`), one team "My team" with the six workflow columns (Backlog, To do, In progress, Testing, Review, Done) and four labels (frontend, backend, qa, bug). **No agents and no routing rules are seeded**; Jeffrey creates agents (name, role, Claude Code, instructions prefilled from the role template, wake-up: manual / when assigned / heartbeat every N minutes) and routing rules on the Team page.
- Workflow defaults (Jeffrey: "as proposed"): labels route the implementer role, Testing → QA role, Review → a human; agents without a heartbeat run only from the Run button; heartbeat agents pick up their next task on their own; caps: 3 QA bounces → hold, 3 failed runs → hold, 45 minutes and 80 assistant turns per run, at most 3 runs at once.
- Editor: Markdown text is canonical (live-preview style); never re-serialise a document.
- Data: SQLite via rusqlite `bundled`; ids are UUIDv7 TEXT; timestamps Unix ms; every write appends to `changes` in the same transaction; soft delete via `deleted_at`. Schema = `DATA-MODEL.md` exactly.
- Data dir: `$GIZAI_DATA_DIR` if set, else `$XDG_DATA_HOME/gizai` (default `~/.local/share/gizai`). Subfolders: `runs/`, `worktrees/`, `files/`.
- Build hygiene (CLAUDE.md): `CARGO_HOME`, npm cache and all build output stay inside `~/Herd/gizai/` (source `scripts/env.sh` before any cargo/npm command). No sudo, no global installs.
- GUI runs during development: only inside a headless cage (`scripts/smoke-cage.sh`). Never on Jeffrey's screen unless he says so; never touch Brave.
- Linux launcher sets `__EGL_VENDOR_LIBRARY_FILENAMES=/usr/share/glvnd/egl_vendor.d/50_mesa.json` when no NVIDIA GPU is present (exit-crash fix from the spike).
- File drops come through Tauri's drag-drop event (paths), not HTML5 `drop` (spike finding). Sorting/filtering of large lists happens in SQLite.

## Review Focus

1. **`claude` not on PATH when Gizai is started from the desktop** (mise shims live in the interactive shell only): resolve the absolute path once via `bash -lc 'command -v claude'`, store it in settings, and show a readable error on the task page if it's missing. Test in Task 13.
2. **Project without a repo, a path that isn't a git repo, or a branch that already exists:** starting a run returns a readable error and changes nothing; an existing worktree for the task is reused. Tests in Task 11.
3. **Gizai quits or crashes while a run is active:** on next start, runs still marked `running` become `failed` with error "interrupted", and their task claims are released. Test in Task 12.
4. **Unknown or malformed lines in the stream-json output** (a newer Claude Code adds event types): the parser keeps the raw line in the log, maps it to `RunEvent::Other`, and never panics. Test in Task 10.
5. **Dutch/Unicode and large Markdown** (é, ë, emoji, a 1 MB description) round-trip through SQLite and the UI unchanged, and task keys with lowercase input are normalised to uppercase. Tests in Task 4.

```rust
use serde::Serialize;

#[derive(Serialize)]
pub struct AppInfo { pub version: String, pub data_dir: String }

#[tauri::command]
fn app_info() -> AppInfo {
    AppInfo { version: env!("CARGO_PKG_VERSION").into(), data_dir: data_dir().display().to_string() }
}

pub fn data_dir() -> std::path::PathBuf {
    if let Ok(d) = std::env::var("GIZAI_DATA_DIR") { return d.into(); }
    let base = std::env::var("XDG_DATA_HOME").map(std::path::PathBuf::from)
        .unwrap_or_else(|_| std::path::PathBuf::from(std::env::var("HOME").unwrap()).join(".local/share"));
    base.join("gizai")
}

pub fn run() {
    tauri::Builder::default()
        .invoke_handler(tauri::generate_handler![app_info])
        .run(tauri::generate_context!())
        .expect("error while running Gizai");
}
```

```ts
// src/lib/format.ts
export function relTime(ms: number, now = Date.now()): string {
  const s = Math.round((now - ms) / 1000);
  if (s < 60) return "just now";
  const m = Math.round(s / 60); if (m < 60) return `${m}m ago`;
  const h = Math.round(m / 60); if (h < 24) return `${h}h ago`;
  const d = Math.round(h / 24); return d === 1 ? "yesterday" : `${d}d ago`;
}
```
